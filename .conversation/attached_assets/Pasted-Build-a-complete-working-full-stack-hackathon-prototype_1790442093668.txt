# 16. MODULE A — FINANCIAL & TEMPORAL

Implement:

## Cost-per-unit anomaly

Use:

- peer groups
- Z-score
- IQR

Compare similar projects by work type and geographic peer group.

Do NOT use one nationwide cost threshold.

Output example:

"Cost per unit is significantly above district peer median."

---

## Near-duplicate works

Use:

- project description similarity
- fuzzy text matching
- location similarity

Use rapidfuzz where practical.

Do not flag based only on text similarity.

---

## Progress-silence / dormancy

Use peer-relative progress velocity.

Do not use a simplistic fixed number of days.

Exclude officially ON_HOLD projects.

---

## Isolation Forest

Use scikit-learn Isolation Forest to detect unusual utilization/expenditure-vs-completion behavior.

Create agency and district analytical features.

If insufficient peer data exists:

show:

"Insufficient data"

rather than fabricating a score.

---

## Ineligible category

Use structured category information.

Free text may provide a secondary signal but must not be the sole basis for an automatic high-risk classification.

---

## Cross-cycle duplicate asset

Compare:

- work description
- location
- fiscal year
- project characteristics

Require supporting evidence.

---

## No-tender

Detect projects where tendering is expected but not recorded.

---

## Missing UC

Detect missing utilization certificates.

Missing UC alone should not create a high fraud risk.

---

## Agency concentration

If one agency handles a large share of works in a geographic area:

show:

"Agency concentration advisory"

This should NOT independently increase risk.

---

# 17. MODULE B — VISUAL & SPATIAL
